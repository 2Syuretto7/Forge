(https://github.com/karpathy/char-rnn/tree/master/data/tinyshakespeare). SHA-256
`86c4e6aa9db7c042ec79f339dcb96d42b0075e16b8fc2e86bf0ca57e2dc565ed`. Used by the L09 and L10 notebooks,
which read this file when run from the repository and otherwise download the same file and check the hash.
