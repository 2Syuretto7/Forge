# Capstone: an honest evaluation report

Report a classifier's accuracy on 2,000 test examples with a guaranteed Hoeffding interval and an approximate bootstrap interval, then measure what test-set reuse does: select the best of 1,000 guessing models on one test set, re-evaluate it on a fresh one, and compare the inflation with the union bound. Write it up as you would for a team that has to trust the number.
