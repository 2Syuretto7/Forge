# Recall bridge: from expressions to machines

In M02 an expression such as $3x + 2$ was something to solve: find the $x$ that makes it equal 11. This lesson turns it around and treats the expression as a **machine**: feed in any $x$, get out $3x + 2$. Clear your M02 cards above first.

:::

## From an equation to a function

The equation $3x + 2 = 11$ asks a question about one output. The function $f(x) = 3x + 2$ answers the question "what comes out?" for every input at once. Solving the equation is then **inverting** the function: given the output 11, which input produced it? You did exactly this with the balance in M02, and this lesson builds inverses in general.

Two habits from M02 carry straight over. The expression tree you built is a description of a machine, and its evaluator is the machine running. The random-point checker compared two machines by running both on the same inputs: two functions are equal when they agree on every input.
