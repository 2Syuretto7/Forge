# Explain it plainly: why order matters

Explain composition to a 12-year-old using two actions from real life.

Guidelines:

- Write 150 to 400 words.
- Pick two everyday actions whose order matters (putting on socks and shoes, adding milk and stirring) and two whose order does not.
- Connect the actions to two number machines, such as "square it" and "add 1".
- Say what it takes to undo two actions done in a row.

:::feynman{id=f1 prompt="Explain why f(g(x)) and g(f(x)) are usually different, using a real-life pair of actions, and say how you would undo two actions done one after the other." key_points="A function is a machine that turns each input into one output|Composing means feeding the output of one machine into the next, so the order is part of the recipe|Each machine changes its input differently, so the second machine sees a different thing depending on which went first|Some pairs happen to commute, but most do not, as squaring and adding one show|To undo two steps you undo the last one first, like taking off shoes before socks"}
:::
