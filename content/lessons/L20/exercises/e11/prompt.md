# Break it: evaluating on what you trained on

The fine-tuning data and the evaluation set were generated by the same script, and some evaluation prompts also appear in training. `normalize` is provided.

1. `leaked_items(eval_prompts, train_prompts)`: the indices of evaluation prompts that appear in the training prompts after normalization.
2. `honest_accuracy(correct, leaked)`: accuracy over all items, over the clean ones and over the leaked ones.

## Hints

1. Put the normalized training prompts in a set.
2. A large gap between the leaked and clean accuracies means the overall number measures memory.
3. Report the clean accuracy, and build the evaluation set before the training set so they cannot overlap.
