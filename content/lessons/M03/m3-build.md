# Build: logic, sets and a counterexample hunter

You will build truth tables, quantifiers over finite sets, set operations from scratch, functions as sets of pairs, and a hunter that searches for counterexamples. In Python, `True` and `False` are the truth values, and `and`, `or`, `not` are the connectives. A function can be passed as an argument like any other value, which is how you will hand a predicate to a quantifier.
