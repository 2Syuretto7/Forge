# Explain it plainly: the order of "for every" and "there is"

You have negated quantifiers, swapped them, and found a counterexample to a swap. Now explain the difference to a 12-year-old.

Guidelines:

- Write 150 to 400 words.
- Use an everyday example (keys and locks, people and mothers, students and seats).
- Explain which of the two statements is stronger and why.
- Say what it takes to show each statement is false.

:::feynman{id=f1 prompt="Explain the difference between 'for every x there is a y' and 'there is a y for every x' using an everyday example, and say which is stronger." key_points="In 'for every x there is a y', each x may get its own different y|In 'there is a y for every x', one single y must work for all the x at the same time|The second statement implies the first, but the first does not imply the second|Swapping the order can turn a true statement into a false one, as every person has a mother but no one is everyone's mother|To show a 'for every' statement is false you need just one counterexample"}
:::
