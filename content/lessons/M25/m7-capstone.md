# Capstone: an A/B test analyzer that knows when to doubt itself

Variant A of a web page converts $k_A$ of $n_A$ visitors and variant B converts $k_B$ of $n_B$. Build an analyzer that answers "is B better?" with the bootstrap and with Bayesian posteriors, run it on four scenarios from a large clear effect to a small test, and write a report on when the two answers agree, when they disagree, and why.
