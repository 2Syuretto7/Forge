# Build: Python as a calculator, units and Fermi worksheets

Time to turn the derivation into code. Each exercise below opens in a workspace with an editor on the right. You write Python functions; hidden tests call them and check the results. If you have never written Python, the first exercise teaches you everything you need for the rest of the lesson; read its instructions slowly.

Several exercises in this lesson carry **invariant** checks: properties that must hold for every input (converting a number to scientific notation and back gives the number you started with). Invariants are how you test code whose exact outputs you cannot list in advance.
